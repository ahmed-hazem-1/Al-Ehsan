# DESIGN.md

## Style Name

Primary style:
- Minimal Swiss-Inspired Landing Page

Closest design labels:
- Editorial SaaS Landing Page
- Neo-Grotesk Minimalism
- Soft Card Interface
- Modern Web Minimalism
- Clean Product Showcase Hero

This is not glassmorphism, not neumorphism, and not brutalism.
It is a clean modern landing-page style that mixes Swiss typography discipline with soft rounded product UI.

---

## Visual DNA

The design is defined by:

- Large bold sans-serif hero headline
- Very spacious white/light-gray background
- Centered hero composition
- Minimal top navigation
- Rounded floating content cards
- Soft depth with subtle shadows or lifted layers
- Small outline icons in circular containers
- Clean CTA buttons with simple contrast
- Focus on one visual centerpiece

Overall feeling:
- Calm
- Premium
- Modern
- Creative-tech
- Lightweight
- Clean but not sterile

---

## What To Call It

If you want to describe it to a designer or developer, say:

> "I want a minimal Swiss-inspired SaaS landing page with a large editorial headline, floating rounded cards, soft depth, monoline icons, and a white spacious layout."

Shorter version:

> "Minimal editorial SaaS style with Swiss typography and soft floating cards."

## Typography Style

Typography is one of the strongest signals in this design.

Characteristics:
- Neo-grotesk / geometric sans-serif look
- Extra-large bold hero text
- Tight, confident headline composition
- Small clean nav labels
- Very low decoration
- Strong contrast between hero title and supporting text

Good font directions for this style:
- Inter
- General Sans
- Satoshi
- Helvetica Now style
- Neue Haas Grotesk style
- Manrope
- Circular-style sans
- SF Pro Display style

Typography rules:
- One huge hero heading
- Short supporting paragraph
- Small simple labels
- No fancy serif
- No playful type
- No excessive font mixing

## Layout Style

The layout style is:

- Single focal-point hero
- Symmetrical overall balance
- Large empty margins
- Floating central visual object
- Clean header with lots of breathing room
- Limited text blocks
- No dense feature grid above the fold

Layout keywords:
- Centered hero
- Spacious framing
- Floating composition
- Visual-first landing page
- High whitespace ratio

This kind of layout is often used in:
- Startup landing pages
- Creative platforms
- Portfolio marketplaces
- Design tools
- Premium SaaS products

## Card / Visual Treatment

The hero artwork uses overlapping rounded cards arranged in a slightly arced fan layout.

That gives the page:
- Depth
- Motion
- Collectible feel
- Showcase feel
- Creative platform energy

This card treatment can be described as:
- Floating media cards
- Layered showcase cards
- Overlapping gallery tiles
- Soft-stack hero cards

Important visual traits:
- Rounded rectangle shapes
- Slight rotation differences
- Overlap for depth
- Soft shadow/elevation
- Center-stage arrangement

## Color Style

The color system is mostly neutral with a few accent moments.

Main traits:
- White or light warm-gray background
- Black or near-black typography
- Sparse accent colors
- Color used mainly in artwork, not in the UI chrome
- Neutral UI shell that lets the central visual stand out

This means the design language is:
- Minimal neutral interface
- Accent-light branding
- Content-led color usage

For your violet version:
- Keep the page white
- Use violet only for buttons, active states, pills, links, and tiny accents
- Avoid flooding the entire page with violet
- Let the composition stay mostly neutral

## Interaction Style

This style usually feels best with:

- Fast transitions
- Subtle hover states
- No heavy animations
- No bouncy effects
- No glowing buttons
- No exaggerated shadows
- Smooth card hover or slight lift only if needed

Recommended interaction feel:
- Quick
- Crisp
- Quiet
- Premium
- Minimal

Suggested transition speed:
- 140ms to 180ms

## Design Principles To Keep

If you want to recreate this style, keep these rules:

1. Use a huge clean headline.
2. Keep the background mostly white.
3. Use one strong visual centerpiece.
4. Keep the navigation tiny and light.
5. Use rounded cards, not sharp rectangles.
6. Use thin outline icons.
7. Keep buttons simple and solid.
8. Avoid visual clutter.
9. Use whitespace aggressively.
10. Let hierarchy do the work instead of decoration.

---

## Avoid These Mistakes

To stay in this style, avoid:

- Heavy gradients
- Glow effects
- Glassmorphism panels
- Overdecorated icons
- Too many colors in the UI
- Thick borders everywhere
- Large shadows on buttons
- Busy feature sections above the fold
- Multiple competing hero visuals
- Fancy typography pairings
